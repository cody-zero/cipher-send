2. What CipherSend Is (and Is Not)

CipherSend is a browser-to-browser tool for sharing short-lived text secrets — passwords, API keys, private keys, or TOTP seeds — with exactly one other person, one time, with end-to-end encryption.

  • It is not a file-sharing tool, a message archive, or a password manager.
  • It is not intended for storing or persisting any data.
  • It is not a replacement for secure access-management tools used by teams on an ongoing basis.

3. Acceptable Use

4. No Account Required

5. How Sessions Work

  • Each session supports exactly two participants (the Host and one Guest).
  • Sessions are single-use and self-expiring (idle timeout and hard time limit, enforced server-side).
  • Secrets, encryption keys, and verification phrases are processed entirely within the browser and are never accessible to CipherSend's servers.
  • Once a session ends, there is no way to recover or retrieve any data from it.
